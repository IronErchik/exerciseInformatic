Сайт про GitHub

Чтобы открыть сайт, нажмите два раза на index.html.
Ничего устанавливать не нужно.

index.html — весь текст и разметка сайта.
style.css — оформление сайта.
script.js — переключение вкладок, кнопки и примеры.
images — три фотографии, сгенерированные с помощью ИИ.

На сайте пять вкладок. Для работы кнопок нужен JavaScript.
Для загрузки дополнительного шрифта нужен интернет.
Без интернета используется обычный системный шрифт.
